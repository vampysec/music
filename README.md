# Vampy Music · Reproductor

Reproductor de música en HTML, CSS y JavaScript que reproduce listas de YouTube Music con la API oficial de YouTube IFrame.

## Listas

- **El Seis · Puras Cumbias** (28 canciones) — https://music.youtube.com/playlist?list=PLdG4OvyaBHu2yDlXFO95gtaoWQxbxBLGc
- **El Seis · Éxitos de Rap** (63 canciones) — https://music.youtube.com/playlist?list=PLdX0aFIvonZ1DkmhFr4AAXsdMLBYHg9TC

## Funciones

- Reproducir / pausa, anterior y siguiente
- **Modo aleatorio** (botón 🔀 Aleatorio)
- Barra de progreso con salto a cualquier punto de la canción
- Control de volumen
- Cambio entre las dos listas con un toque
- Lista de canciones con portada, título y la canción actual resaltada

## Archivos

- `index.html` — estructura del reproductor
- `style.css` — diseño oscuro estilo VSEC-MX
- `app.js` — lógica del reproductor (API de YouTube IFrame)
- `playlists.js` — las dos listas con sus canciones

## Cómo usarlo

Abre `index.html` en el navegador, o actívalo con GitHub Pages desde la configuración del repositorio (rama `main`, carpeta raíz) para tenerlo en vivo.
